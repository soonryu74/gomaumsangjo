# 장례 기록 — 하나 더하는 법

기록 하나 = 파일 하나입니다. 목록(`/girok.html`)은 손으로 고치지 않습니다.
`tools/girok.mjs` 가 이 폴더를 읽어 목록과 사이트맵을 다시 씁니다.

## 절차

```bash
node tools/girok.mjs --new 2026-09-anyang-metro   # 연-월-영문이름
# 만들어진 파일을 열어 아래 둘을 채웁니다
#   1) <head> 안의 gm-girok 덩어리 — 날짜·장례식장·일수·한 줄 요약·동의
#   2) <article class="rec"> 안의 제목과 본문
node tools/girok.mjs --write                      # 목록·사이트맵 갱신
node tools/check.mjs                              # 어긋난 곳이 없는지
```

## 규칙

- **유족 동의(`consent`)가 비어 있으면 목록에 오르지 않습니다.** 생성기가 거부합니다.
  동의를 받은 달을 `"2026-09"` 꼴로 적습니다.
- 이름, 나이, 직업, 빈소 호실, 선영 위치는 적지 않습니다.
  장례식장과 화장시설 이름은 공개된 시설이라 그대로 적습니다.
- 가족의 말씀은 동의를 받은 것만, 그대로 옮깁니다.
- 생성기는 `girok.html` 의 표시된 구간만 건드립니다.
  **이미 있는 기록 파일은 열지도 않습니다.** 기존 글이 깨질 수 없습니다.

## 왜 이렇게 만들었나

목록을 JSON 으로 두고 자바스크립트로 그리는 방법도 있습니다.
쓰지 않았습니다. **네이버 검색로봇은 자바스크립트를 거의 돌리지 않습니다.**
목록이 진짜 HTML 로 미리 쓰여 있어야 네이버에 걸립니다.
기록 하나하나도 제 주소를 가진 쪽이라 따로 검색되고 따로 보낼 수 있습니다.
