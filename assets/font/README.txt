gm-brush-subset.woff2

나눔손글씨 붓(Nanum Brush Script, NHN/네이버)에서 '고맙습니다' 다섯 글자만
남긴 부분집합입니다. 홈 첫 화면의 손글씨 한 마디에만 씁니다.

원본 글꼴은 SIL Open Font License 1.1 (OFL.txt) 로 배포됩니다.
OFL 은 원본 이름(Reserved Font Name: Nanum, NanumBrush 등)을 고친 판에
쓰지 못하게 합니다. 이 파일은 글자를 덜어낸 고친 판이므로,
CSS 에서는 "GM Brush" 라는 다른 이름으로 부릅니다.

원본: https://fonts.google.com/specimen/Nanum+Brush+Script
